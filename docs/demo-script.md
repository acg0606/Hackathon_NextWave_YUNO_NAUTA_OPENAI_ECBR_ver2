# Five-Minute Judge Demo

## 0:00 — Establish the promise

Open RouteShift and state: “The flow is the source of the experience.” Point out the current `runId`, revision, owner, truth legend, realistic Earth, and flow graph.

## 0:30 — Show three independent operations

Switch among Booking preparation, Vessel departed, and Unexpected transshipment. The active surface must change with each snapshot while run IDs and event histories remain isolated.

## 1:15 — Apply evidence

Open the disruption archive and select Iskenderun. Show the historical source and date, current NASA context with freshness, live corridor traffic when available, simulated present-day consequences, Yuno Sandbox state when configured, and the Nauta mock as separate truth classes.

Open **Integrations**. Explain that a configured capability is not called “live” until a validated run event records a successful observation. The panel never receives secret values.

## 2:00 — Mutate the flow live

In Flow Mutation Lab enter:

“Validate Bill of Lading against booking before confirming.”

Submit while the server remains running. Point out:

- the flow version increment;
- the newly discovered cue;
- the random step ID;
- `flow.definition.updated`;
- `step.discovered`;
- `ui.spec.emitted`;
- the message “FLOW CHANGED → ARI UNDERSTOOD → UI RECOMPOSED.”

## 2:45 — Prove semantic composition

The generated interface must compare:

- POD `TRISK` versus `TRMER`;
- gross weight `18,240 kg` versus `19,050 kg`;
- delta `810 kg / 4.44%`;
- confidence `98%`;
- blocking severity.

Explain that the renderer knows `document.compare`, not the random step ID.

## 3:30 — Prove the human loop

Capture the current run ID. Select “Request corrected B/L.” Show:

- `human.action.received`;
- mock correction;
- artifact update;
- `run.resumed`;
- validation retry;
- successful match;
- booking confirmation.

Confirm that the run ID is unchanged and the obsolete comparison controls left the DOM.

## 4:20 — Prove repeatability and safety

Insert the same semantic step with another generated ID. Then run an AIR shipment and show `step.skipped`. Mention strict schemas, finite capabilities, stale-revision rejection, idempotency, hosted D1 durability, and the clearly labeled local-memory preview fallback.

## 4:50 — Close

“RouteShift does not generate code. It understands a changed flow, records what happened, and safely rebuilds the operational interface around the new reality.”
